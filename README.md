# Deutsch jeden Tag

Denní 10minutový trénink němčiny do mobilu. Funguje offline.

- **Trénink**: jedno tlačítko START, appka sama míchá slovíčka a gramatiku.
- **Gramatika** (`gramatika.js`): 44 témat A1 → A2 → B1 podle rozsahu zkoušky Goethe-Zertifikat B1 + 3 bonusová (B2). Vstupní test, tahák ke každému tématu, závěrečný test každé úrovně, Blitz 60 s. Téma je na 100 %, když ho dáš ve 3 různých dnech 5× za sebou bez chyby a aspoň dvěma typy cvičení.
- **Slovníček**: 5 044 položek ze slovníku Němčina 6034, hledání česky i německy.

Appka: https://mvk17.github.io/nemcina/
